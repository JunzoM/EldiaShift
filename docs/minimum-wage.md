# 最低賃金の表の更新（毎年）

アプリは起動時に、リポジトリの `minimum-wage.json`（main ブランチ）を読み込みます。
毎年の改定は、この JSON を直して main にマージするだけで、アプリの更新を待たずに届きます。

## いつ
- 8月：中央最低賃金審議会の目安
- 8〜9月：各都道府県の答申（金額と発効日が決まる）
- 10月〜12月：都道府県ごとに発効

金額と発効日がそろったら（9月ごろ）更新します。

## 手順
1. 厚生労働省「地域別最低賃金の全国一覧」で、47都道府県の金額と発効日を確かめる
2. `minimum-wage.json` を直す
   - `year` を新しい年度にする（アプリは今の表と同じか新しい年度の表だけを使う）
   - `updated` を直した日にする
   - 各都道府県の配列の最後に `{"from": "YYYY-MM-DD", "amount": 金額}` を足す
   - 古い金額は消さずに残してよい（過去の月の判定に使う）。長くなったら、2年より前の金額は消してかまわない。いちばん古い金額は `from` なしにする
3. PR → CI が通ったらマージ（ここでアプリに届く）
4. 次にアプリを出すときに、`EldiaShift/MinimumWage.swift` の `bundled` も JSON と同じ内容にする（ネットにつながらない人や新しく入れた人にも新しい表が使われるように）。同じ年度のときは、テストで JSON と一致するか確かめる

## 決まり
- `from` は発効日。その日から新しい金額を使う
- `from` がない金額は、次の金額の発効日の前日まで使う
- 47都道府県がそろっていない・金額がおかしい表は、アプリが使わない（アプリに入っている表のまま）
- 店舗の設定で「手で入れる」に金額があるときは、表よりそちらを使う
