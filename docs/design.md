# デザインの決まり（SHIFT）

画面ごとに大きさ・余白・角の丸みがばらばらにならないよう、数字は `DS`（`EldiaShift/StyleParts.swift`）と `AppFont`（`EldiaShift/EldiaShiftApp.swift`）から使う。
HOTEL-SHIFT（FIXED560）の Mac 版の決まり（角丸 14・外側の余白 16・幅いっぱい）に合わせている。

## 決まり

| 名前 | 値 | 使うところ |
|---|---|---|
| `DS.page` | 16 | 画面の外側の余白 |
| `DS.gap` | 12 | カード同士・部品同士の間 |
| `DS.section` | 20 | 見出しのまとまり同士の間 |
| `DS.cardPadding` | 16 | カードの内側の余白 |
| `DS.cardRadius` | 14 | カード・面・パネルの角 |
| `DS.controlRadius` | 10 | ボタン・入力・選ぶ部品・サイドバーの項目の角 |
| `DS.chipRadius` | 8 | 勤務の記号・日付のマスなど小さな印の角 |
| `.appFont(.number)` | 32pt 太字・丸ゴシック | 大きな数字（ホームのカード・人件費の合計） |

- 文字は `.font` ではなく `.appFont` で書く（Mac の 表示 → 拡大・縮小 が効く）。
- 角の丸み 2〜4 の細い印（表のマスの中の帯など）は、この決まりの外にしている。
- 印刷の中身・QR ポスター・個人の予定表の画像・似顔絵の絵は、紙や画像の決まりがあるので、この決まりを使わない。

## 2026-10 の見直しで直したこと

### 角の丸み（49か所）
1. カード・面の角が 14 と 16 の2種類あった → **14 にそろえた**（ホームのカード・見出しの面・店舗のカード・印刷の各パネル・会社の帯・バックアップのカード）
2. ボタン・選ぶ部品の角が 10・12・13 の3種類あった → **10 にそろえた**（クイックメニュー・出力形式の選択・店舗の選択・勤務の記号の選択・サイドバーの項目）
3. 小さな印の角が 6・8・9 の3種類あった → **8 にそろえた**（勤務の記号・日付のマス・申請の日付・タイムラインの枠・QR の見本）

### 余白・間隔
4. ホームの数字のカードの内側が 14、ほかのカードは 16 → **16 にそろえた**
5. ホームの見出しの面の左右が 14 → **16 にそろえた**
6. バックアップのお知らせの内側が 12 → **16 にそろえた**
7. バックアップ画面のカードの内側が 18 → **16 にそろえた**
8. 画面の外側の余白が 16 と 20 の画面があった（バックアップ・店舗の詳細が 20）→ **16 にそろえた**
9. ホームの左右の列の間が 16、カードの間が 12、まとまりの間が 20 と混ざっていた → **列とカードの間は 12、まとまりの間は 20 に整理した**

### 幅・高さ
10. Mac のホームだけ幅の上限（1500）があり、左右に大きな余白ができていた。ほかの画面は幅いっぱい → **Mac はホームも幅いっぱいにした**（HOTEL-SHIFT の Mac 版と同じ）
11. サイドバーの幅が文字の大きさに関係なく 240 で、文字を大きくすると「サイドバーをたたむ」が2行に折り返していた → **文字の倍率に合わせて幅も広げる**
12. サイドバーの「サイドバーをたたむ」だけ、文字が一回り小さく、高さも低かった → **ほかの項目と同じ文字・同じ高さにした**

### 文字・字体
13. 設定の画面だけ題名が大きな左寄せ（ラージタイトル）で、ほかの画面は小さな中央の題名だった → **設定も中央の題名にそろえた**
14. 大きな数字の字体が、ホームは 32pt の丸ゴシック、人件費の合計は 34pt のふつうのゴシックと違っていた → **どちらも `.appFont(.number)`（32pt 太字・丸ゴシック）にそろえた**
15. 拡大・縮小で変わる文字と変わらない文字が混ざっていた（#53・#54 で対応）→ 画面の文字はすべて `.appFont`、セグメントと題名は UIKit の見た目で倍率をかける

## まだ残っていること

- シフト表のマスの中の文字（8〜10pt）は、マスの幅が決まっているので小さいまま。Mac で拡大すると、マスに入りきらない文字は切れることがある。
- iOS 26 の上のバー（ガラスのボタンのまとまり）は OS が描くので、ボタンの大きさは画面ごとに OS の決まりのまま。
