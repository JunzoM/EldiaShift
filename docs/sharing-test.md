# iCloud 共有の確かめ方（実機）

共有は自動のテストでは確かめられないので、**Apple ID が違う2台**で確かめる。
A＝共有する人（オーナー）、B＝招待される人。どちらも最新の版を入れ、設定の「iCloud で同期する」をオンにしておく。

## 前もって
- [ ] Xcode の Signing & Capabilities（iOS と Mac の両方）で、権限に `com.apple.developer.icloud-extended-share-access`（`InProcessOneTimeLinks`）が入っていることを確かめる。無いと iOS 26 以降で「To use one time links, you must have the … entitlement」と出て、共有も iCloud 同期も始まらない
- [ ] CloudKit Console で、開発（Development）のスキーマに `PayRecord`（key・wages・updatedAt）と `CellRecord.note` があることを確かめる（開発ビルドを一度動かすと作られる）
- [ ] TestFlight / App Store に出す前に、スキーマを本番（Production）へ反映する（Deploy Schema Changes）

## 1. 1.0 からの更新（A だけ）
- [ ] App Store の 1.0 にデータがある端末へ、TestFlight の 1.1 を上書きで入れる → 店舗・部門・スタッフ・シフトがそのまま残る
- [ ] 時給を入れると、給与の画面と人件費に出る（1.0 には給与の項目が無い）

## 2. 共有する（A）
- [ ] 設定 →「シフト表の共有」→「シフト表を共有する」→ Apple の共有の画面が出る
- [ ] 「編集できる」で B にメッセージで送る
- [ ] iPad（横・縦）と iPhone で、共有の画面が画面の外にはみ出さない

## 3. 受け取る（B）
- [ ] リンクを押すと SHIFT が開き「共有されたシフト表を受け取りました」と出る
- [ ] 少し待つと、A のシフト表（店舗・部門・スタッフ・シフト）に切り替わる
- [ ] SHIFT を閉じた状態でリンクを押しても受け取れる
- [ ] iCloud 同期がオフの B でも、受け取るとオンになって受け取れる

## 4. 給与が共有されないこと
- [ ] B のスタッフを開いても、給与の欄が**出ない**（「編集できる」でも「見るだけ」でも）
- [ ] A と B の両方に見本のデータを入れた（または A のバックアップを B に入れた）状態でも、共有されたシフト表に時給が**出ない**
- [ ] B の集計に「人件費」が**出ない**。ホームの人件費のカードは「—」で「共有されたシフト表では出しません」
- [ ] B が自分のシフト表に戻すと、自分の給与・人件費はいつも通り出る
- [ ] A の給与・人件費はいつも通り出る

## 5. 共同編集
- [ ] B がマスを変えると、A の表にも出る（数十秒かかることがある）。逆も同じ
- [ ] B が希望休の申請を受け取ると、A の承認待ちにも出る
- [ ] 同じマスを同時に変えたとき、新しく入れた方が残る

## 6. 見るだけ
- [ ] A が共有の画面で B を「見るだけ」に変える → A のアプリが固まらず、落ちない（古い iPad でも）
- [ ] 共有の画面を開いたまま権限を3〜4回続けて切り替えても、「オプションを変更できませんでした」と出ず、毎回1回で切り替わる
- [ ] 共有の画面を閉じると、B の画面（メニュー・編集できるか）が数秒で変わる（SHIFT を開き直さなくても）
- [ ] 権限の切り替え・画面を閉じるのを何度くり返しても、B のシフト表の中身が消えない（A の「参加者を管理する」で同じ参加者のまま。新しい共有にならない）
- [ ] B のメニューが、ホーム・シフト表・集計・印刷・出力・設定だけになる（iPad のサイドバー・iPhone の下のタブ）
- [ ] B の設定に、スタッフ・店舗・会社・シフト表の中身・バックアップ・すべて消去が出ない。「シフト表の共有」は出る
- [ ] B のホームのクイックメニューに、スタッフ・スタッフを追加・希望休・店舗が出ない
- [ ] B がマスを変えようとすると「見るだけで共有されています」と出て、変わらない
- [ ] A が「編集できる」に戻すと、B のメニューが元に戻る

## 7. 切り替え・やめる
- [ ] B に自分のシフト表もあるとき、設定 →「シフト表の共有」で2つが出て、切り替えられる。混ざらない
- [ ] B が「共有から抜ける」→ 共有されたシフト表が消え、自分のシフト表に戻る
- [ ] A が「共有をやめる」→ B から消える。A のデータはそのまま

## 8. 同じ Apple ID の2台（A の iPad と iPhone）
- [ ] A の iPhone にも共有中のシフト表がそのまま出る（チームが2つにならない）
- [ ] A の iPhone の給与の画面に時給が出る（自分の端末どうしでは同期する）
